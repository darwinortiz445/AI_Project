
# AI Project: Sistema de Recomendación con GitHub Copilot

Actividad formativa de exploración de tendencias emergentes en Inteligencia Artificial utilizando GitHub Copilot en INACAP.

## Descripción del Proyecto
Este proyecto implementa un sistema de recomendación basado en aprendizaje automático usando Python (`pandas` y `scikit-learn`), desarrollado como parte de las actividades prácticas de la asignatura.

## Pasos Realizados
1. Creación del repositorio `AI_Project` en GitHub[cite: 4].
2. Clonación y apertura del proyecto en Visual Studio Code.
3. Desarrollo del script de Python `recommendation_system.py`[cite: 5, 6].
4. Subida y control de versiones mediante Git.
